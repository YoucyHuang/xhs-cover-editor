# 小红书封面生成器 · 使用说明

**在线直接用：<https://youcyhuang.github.io/xhs-cover-editor/>**（电脑、手机都能打开，不用登录）

一个在自己电脑上运行的小网页，用来做 3:4 的小红书封面（导出 1242 × 1656 px）。
**不需要安装任何东西，不需要 npm，不需要联网，不需要登录。**

---

## 一、怎么打开

### 方法 1（推荐）：双击启动文件

1. 打开 `xhs-cover-maker` 文件夹
2. 双击 **`双击打开封面生成器.bat`**
3. 会自动用 Chrome 打开编辑器

> 第一次双击时 Windows 可能弹出“Windows 已保护你的电脑”，点「更多信息」→「仍要运行」即可。这个文件只做一件事：用 Chrome 打开 `index.html`（可以右键 →「编辑」看里面的内容）。

### 方法 0：在线版（手机、别的电脑都能用）
打开 <https://claude.ai/artifact/VyjFL5gHg2uC8N8CCayuHZ>（要登录自己的 Claude 账号）。手机上是「画布在上、下面分页编辑」的布局。
- 在线版的自动保存只存在**当前这个浏览器**里，手机和电脑各存各的。换设备接着改：在一边「保存项目」，另一边「打开项目」。
- 在线版字体按需下载，第一次用某个中文字体会慢几秒。
- 导出 PNG / 保存项目时会先弹一个确认保存的窗口，点同意才会下载。

### 方法 2：直接用 Chrome 打开网页文件

1. 在 `index.html` 上点右键
2. 选「打开方式」→「Google Chrome」

> 如果你的默认浏览器已经是 Chrome，直接双击 `index.html` 也可以。

**小技巧**：打开后按 `Ctrl + D` 把它加入 Chrome 书签，以后点书签就能打开。

## 三、常用操作

| 想做什么 | 怎么做 |
|---|---|
| 放照片 | 把照片**直接拖进画布**，或点顶部「上传照片」。照片默认铺满整个画布 |
| 调整照片位置 | 点一下照片选中它 → 在画布上拖动 |
| 缩放照片 | 选中照片后用滚轮，或右侧「缩放」滑块 |
| 照片恢复铺满 | 在照片上**双击** |
| 改文字 | **双击画布上的文字**直接改；或者在右侧「文字内容」框里改，两边同步。回车 = 换行，按 Esc 或点别处结束编辑 |
| 移动文字 / 色块 / 签名 | 点中后直接拖。拖动时会自动吸附画布中线和对齐线（按住 `Alt` 可以关掉吸附） |
| 微调位置 | 方向键移动 1px，`Shift + 方向键` 移动 10px |
| 改色块大小 | 选中色块后拖四边或四角的小方块 |
| 色块透明度 / 圆角 | 选中色块，在右侧拖滑块（透明度默认 82%，圆角默认 0） |
| 改色块形状（波浪、拱形…） | 选中色块 → 右侧「形状」点一个预设；或者点画布上的「〰 拖点改形状」（也可以**双击色块**），上下拖色块边上的圆点自由改形状。勾「左右对称拖动」两边一起动；「起伏」滑块整体放大缩小；拖回原位会自动吸附成平的；按 `Esc` 完成 |
| 加金闪 / 泡泡 / 碎光点 | 选中色块往下翻，或在图层列表点「金闪 / 泡泡」，拖「数量」滑块就会出现。可以选撒在色块边缘 / 色块里 / 整张图，点「换一种分布」重新随机摆放。默认在文字下面不挡字 |
| 换字体、字号、字重、颜色、行距、字间距、对齐 | 选中文字后在右侧调整 |
| 文字描边 / 投影 | 选中文字 → 右侧「描边和投影」：一键套用 白描边 / 柔投影 / 错位投影 / 贴纸，或自己调描边粗细颜色、投影颜色浓度模糊和偏移 |
| 切换模板 | 点顶部 `VLOG` / `知识口播` / `合作` / `生活`。**只换颜色和左上角标签，文字和照片都保留** |
| 切换版式 | 左边最上面「版式」：`经典` / `色场编号`。**只换排版，文字和照片都保留** |
| 改模板颜色 | 左边「模板颜色」里点色块打开取色器，**改完自动记住**；点 ↺ 恢复默认色 |
| 放签名 / 手绘涂鸦 | 顶部「上传签名」选一张透明背景 PNG，会放在右下角，可拖动、拖四角缩放 |
| 某个图层总是挡住照片 | 在左边图层列表点锁形图标锁定它，画布上就点不中它了 |
| 撤销 / 重做 | `Ctrl + Z` / `Ctrl + Shift + Z`（或 `Ctrl + Y`） |

### 四套模板（= 四个栏目颜色）

| 模板 | 左上角标签默认文字 | 颜色 |
|---|---|---|
| VLOG | VLOG · 01 | 雾霾蓝 `#B8C7D6` |
| 知识口播 | 搞钱笔记 · 01 | 奶油黄 `#E8D7A8` |
| 合作 | 合作 · 品牌名 | 藕荷紫 `#D3C3CF` |
| 生活 | 生活 · 01 | 鼠尾草绿 `#C4CFB7` |

每套模板的标签文字是分开记的：比如你把知识口播的标签改成「搞钱笔记 · 07」，切到 VLOG 再切回来，还是「搞钱笔记 · 07」。

> 第 2 版起，「合作」的默认颜色从鼠尾草绿改成了藕荷紫，鼠尾草绿给了新的「生活」模板。如果你之前手动改过合作的颜色，你改的颜色会保留。想换回绿色，在左边「模板颜色」里点合作的色块改就行。

### 两种版式

| 版式 | 样子 | 适合 |
|---|---|---|
| **经典** | 照片铺满整张图，底部一块半透明标题色块，左上角系列标签 | 想让照片占满画面的时候 |
| **色场编号** | 照片在上，纯色块在下；色块左上一排小标签、超大斜体编号压在照片和色块交界处，下面是标题、一条细线、副标题和英文地点 | 做系列封面，主页最整齐 |

- 两个版式各自记住自己的位置和样式。在色场编号里调过的位置，切到经典再切回来还在。
- 色场编号版式里，照片只显示在色块上方。拖色块的**上边**，照片区域就跟着变高或变矮。
- 色场编号版式多了 4 个图层（经典版式里默认隐藏，也可以在图层列表点眼睛打开）：

| 图层 | 怎么用 |
|---|---|
| 大编号 | 双击改成 08、09、10…，一路排下去就是一个系列。默认 Bodoni Moda 斜体 |
| 小标签组 | 文字用 `/` 分隔，比如 `VLOG / 意大利 / 3 DAYS`，每段一个小框，第一个是实心的 |
| 细线 | 可以拖动，拖两端改长度，右侧可改粗细和颜色 |
| 地点 / 英文 | 比如 `Venice, Oct.`，默认 Cormorant 斜体、右对齐 |

- 点画布空白处，右侧可以调「颗粒质感」（加一点胶片颗粒，导出 PNG 时最明显）和「照片柔和滤镜」（降低饱和度，让不同照片色调统一）。色场编号版式默认都开着。
- 右侧还有「恢复本版式默认样式」，调乱了可以一键回到默认（文字和照片保留）。
- 所有文字现在都可以在右侧「字形」里切换正体 / 斜体。

## 四、导出、保存、预览

### 导出 PNG
点右上角「导出 PNG」（或 `Ctrl + E`）。
- 尺寸固定 **1242 × 1656 px**
- 文件名自动生成：`模板名_主标题前8个字_日期.png`，例如 `知识口播_存多少钱能躺平一_20261013.png`
- 文件保存在 Chrome 的默认下载文件夹（一般是「下载」）
- 导出前会检查字体：如果某个字体没加载成功，会先提醒你，不会悄悄变成系统字体

### 自动保存
你做的每一步都会自动存在这台电脑的 Chrome 里，**关掉、刷新都不会丢**，下次打开会回到上次的状态。
- 文字、位置、颜色存在 localStorage
- 照片、签名、上传的字体比较大（localStorage 只有 5MB），存在 Chrome 的本地数据库 IndexedDB 里

> ⚠️ 如果你清理了 Chrome 的「浏览数据 / Cookie 和网站数据」，自动保存的内容会被清掉。重要的封面请用下面的「保存项目」另存一份。

### 保存项目 / 打开项目
- 「保存项目」（`Ctrl + S`）：下载一个 `.json` 文件，里面包含文字、所有设置、照片、签名，以及你用到的上传字体。
- 「打开项目」：选择以前保存的 `.json`，就能接着改旧封面。也可以直接把 `.json` 拖进窗口。
- 打开项目后如果后悔了，按 `Ctrl + Z` 可以回到打开之前。

### 新建
「新建」会清空当前内容（模板颜色会保留），按 `Ctrl + Z` 能找回。

### 主页预览
点「主页预览」，会把你**导出过的封面**按小红书主页双列瀑布流排出来，看整体风格是否统一。
- 每次导出都会自动加进来
- 勾选「包含当前画布」可以把还没导出的这张也放进去对比
- 「添加已有封面图」：把你以前发过的封面截图加进来一起对比
- 手机框里的昵称可以直接点击修改
- 鼠标移到某张封面上，点右上角 × 可以从预览里删掉（不会删除已导出的图片文件）

### 安全区提示
点顶部「安全区」开关，画布上会出现虚线提示（只在编辑时显示，**不会被导出**）：

| 提示 | 含义 |
|---|---|
| 左上角红框「主页置顶标记」 | 笔记被置顶后，主页上这里会盖一个「置顶」标 |
| 右上角红圈「视频笔记播放图标」 | 视频笔记在信息流里这里有播放图标 |
| 上下两条红线「1:1 裁切线」 | 搜索结果、分享卡片等部分入口会按正方形裁切，线外区域可能看不到 |
| 灰色虚线「边缘安全线」 | 文字最好别贴出这条线 |

这些位置是按手机上双列卡片的实际大小估算的，作为参考。另外，当文字在双列信息流里会小到看不清时，右侧面板会出现红色提示。

### 上传自己的字体
点顶部「上传字体」，或者**直接把 `.ttf` / `.otf` 文件拖进窗口**，它就会出现在字体下拉菜单的最下面（标着「我上传的」）。
- 上传的字体会一直保存在这台电脑的 Chrome 里，下次打开还在
- 下拉菜单里点 × 可以删掉
- 请只上传你确认**有商用授权**的字体

### 导出时字体会不会丢？
不会。封面是在网页里直接画成图片的，字体会被“画”进像素里，导出的 PNG 在任何手机、电脑上看都一样。导出前程序还会检查一遍所有用到的字体是否加载成功。

## 七、常见问题

**Q：字体下拉里某个字体显示「缺文件」？**
A：说明 `fonts` 文件夹里找不到它的文件。看第五节，检查文件名是否完全一致（大小写也要一样），然后按 `F5` 刷新。

**Q：双击 `index.html` 打开的是 Edge 或别的浏览器？**
A：用「双击打开封面生成器.bat」，或者右键 `index.html` →「打开方式」→「Google Chrome」。

**Q：换了一台电脑，之前的封面不见了？**
A：自动保存只存在原来那台电脑的 Chrome 里。换电脑请用「保存项目」导出 `.json`，在新电脑上「打开项目」。整个 `xhs-cover-maker` 文件夹可以直接拷贝到 U 盘带走。

**Q：可以把文件夹挪到别的地方吗？**
A：可以，整个文件夹一起挪就行（`fonts`、`css`、`js` 要和 `index.html` 在一起）。

**Q：导出的图在哪？**
A：Chrome 的下载文件夹，按 `Ctrl + J` 可以打开 Chrome 的下载列表。

## 八、文件夹里都是什么

```
xhs-cover-maker/
├── 双击打开封面生成器.bat   ← 双击这个启动
├── index.html               ← 网页本体
├── README.md                ← 就是这份说明
├── css/
│   ├── style.css            ← 界面样式
│   └── fonts.css            ← 字体登记表（哪个字体对应哪个文件）
├── js/
```
